# MyStock 로컬앱 v0.9.65-beta

선물 자동매매의 **포지션 장부 정합성**을 바로잡은 중요한 안정성 업데이트입니다. (LS증권 국내선물 이용 시 특히 중요)

## 무엇이 문제였나

자동매매 앱은 자기가 보유한 포지션을 **자체 장부**에 기록하고, 매일 장 마감 후 이를 **증권사 실제 잔고**와 대조합니다. 그런데 LS증권 국내선물의 경우, 증권사가 잔고에서 종목을 알려주는 **코드 형식**(예: `101T9000`)을 앱이 알아보지 못해, 앱이 **자기 포지션을 "내가 모르는 외부 매도"로 오인**했습니다.

그 결과:
- 앱이 실제로는 계좌에 있는 선물 포지션을 **자기 장부에서 지워버리고**,
- 증권사 실제 잔고와 앱 장부가 **점점 어긋났습니다**(장부는 비었는데 계좌엔 포지션이 남는 식).

## 무엇을 고쳤나

1. **잔고 코드 인식** — LS 국내선물 잔고의 코드 형식(`101…`)을 정확히 인식하도록 했습니다. 이제 앱이 자기 포지션을 제대로 알아봅니다. (KIS·주식은 원래 정상이라 영향 없음)
2. **안전장치 — 함부로 지우지 않음** — 코드 인식이 안 되거나 증권사 잔고 조회가 실패한 상황에서는, 앱이 **선물 포지션을 자동으로 지우지 않고** "정합성 점검 불가"로 **표시만** 합니다. "확실할 때만 정정한다"는 원칙으로 바꿨습니다. (사람이 직접 판 주식을 장부에서 빼주는 기존 기능은 그대로)
3. **종가청산 누락 감지** — 장 마감 정산 때, 당일 청산됐어야 할 당일매매 포지션이 남아 있으면 **경고로 알려줍니다**(예상치 못한 오버나이트 노출을 그날 바로 인지).

## ⚠️ 재개 전 꼭 확인하세요

- 이 수정은 **앞으로의 정합성**을 지킵니다. 이미 어긋난 계좌 상태는 자동으로 되돌리지 않습니다.
- **재개 전 권장 절차:** ① 증권사(HTS/앱)에서 **남아 있는 모의 선물 포지션을 정리(청산)** → ② 앱에서 **자동매매 초기화**(장부 리셋) → ③ 이 버전으로 교체 후 재실행.
- 재개 후 하루 돌려 **모의로 재검증**을 권장합니다: 정산 후 정합성 경보가 없는지, 당일매매가 종가에 청산되는지 확인.

## 검증

엔진·자동매매 테스트 통과(로컬 + 코어 1404, 이번 문제를 그대로 재현하는 회귀 테스트 포함 — 수정 전이었다면 장부가 지워졌을 상황에서 보존되는지 확인). **자동매매 발주 로직 자체는 바뀌지 않았고**, 장부 대조·정규화·정산 감시만 손봤습니다. LS 잔고 코드의 실제 값은 첫 모의 재검증에서 최종 확인되며, 혹시 다른 형식이면 앱 로그에 즉시 경고가 남도록 했습니다.

## 업데이트 방법

로컬앱을 종료하고 이 버전으로 교체한 뒤 다시 실행하세요. (장 마감 후 또는 개장 전 권장 — 위 "재개 전 절차"를 함께 진행.)
