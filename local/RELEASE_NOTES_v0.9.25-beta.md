# v0.9.25-beta

## 🔴 모의투자 시세 조회 복구 — 시세용 실전 앱키 (필수)

KIS가 **모의 앱키의 실시간 시세 조회를 차단**(EGW02004)하도록 정책을 강화해, 모의투자에서
US·국내 종목의 **장중 손절·익절·청산·전량매도가 현재가 미수신으로 동작하지 않던** 문제를
근본 해결했습니다.

- KIS는 시세를 **실전 도메인 전용**으로 제공하고 모의 앱키를 거부합니다. 따라서 모의투자라도
  **시세 조회에는 실전 앱키가 필수**입니다.
- 이제 자격증명 설정에 **"시세용 실전 App Key/Secret"** 칸이 추가됐습니다. **주문·잔고는
  모의 앱키(모의계좌)로, 시세 조회만 실전 앱키로** 호출합니다. 입금·실거래는 필요 없습니다.
- **모의투자는 이 시세용 실전 앱키가 없으면 자동매매가 시작되지 않습니다**(장중 청산 보장).
  실전투자 모드는 주문 앱키가 곧 실전이라 추가 입력이 필요 없습니다.

### 설정 방법
1. KIS 개발자센터에서 **실전투자 App Key/Secret** 발급(주식 시세 권한 포함).
2. 로컬앱 `⚙ 자격증명·페어링 변경` → "시세용 실전 App Key/Secret" 입력 후 저장.

검증: 단위 5(이중 앱키 라우팅·필수·토큰) + 토큰 캐시 회귀 + local 전체 315 green.
실측: 모의 계정에서 실전 시세 앱키로 AAPL·AMZN·삼성전자 현재가 정상 수신 확인.
