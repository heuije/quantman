# MyStock 로컬앱 v0.9.61-beta

선물 자동매매의 **레버리지 기본값**과 **실전계좌 연동 흐름**을 개선한 업데이트입니다.

## 선물 기본 레버리지 — 20% → 100%(풀레버리지)

- 선물 증거금 사용률 기본값이 **20%**였습니다. 이 경우 레버리지가 **약 1배(거의 무레버리지)**라
  선물을 써도 레버리지 효과가 없었습니다. 자연어 전략 빌더에서도 사용률을 따로 적지 않으면 20%로
  떨어져 혼란을 줬습니다.
- 이제 기본값이 **100%(풀레버리지 ≈ 5배)** 입니다 — 선물은 레버리지가 기본 의도이기 때문입니다.
- 레버리지를 낮추려면 전략 빌더의 **증거금 사용률**을 낮추면 됩니다(사용률 = 레버리지 × 증거금률).
- ⚠ **기존에 저장한 전략은 그대로 유지**됩니다(저장된 값이 보존되므로 자동으로 5배로 바뀌지 않음).
  새로 만드는 선물 전략부터 기본 100%가 적용됩니다.
- 증거금 사용률을 **0(또는 음수)으로는 저장할 수 없습니다** — 0이면 한 계약도 발주되지 않아 막았습니다.

## 실전계좌 즉시 연동

- 로컬앱에 **실전 자격증명을 등록**해도, 웹앱 "계좌에 적용"에 **모의계좌만 뜨고 실전계좌가 안 뜨던**
  문제를 고쳤습니다.
- 원인: 자격증명 저장 후 계좌 정보가 서버로 즉시 전송되지 않아(거래 사이클·상태변경 때만 전송됐음)
  웹이 옛 정보를 보여줬습니다.
- 이제 **자격증명 저장 즉시** 계좌 정보가 웹에 반영됩니다 → 실전 자격증명 등록 → 웹에서 실전계좌 선택
  → 전략을 실전으로 적용 → 로컬앱이 실전 자동매매 실행, 이 흐름이 매끄럽게 동작합니다.

## 검증

엔진·자동매매 전체 테스트 통과(core 598 · 서버 457 · 로컬 680). 선물 실전 발주·체결은 계좌 입금 후
별도 검증 대상입니다.

## 업데이트 방법

로컬앱을 종료하고 이 버전으로 교체한 뒤 다시 실행하세요.
