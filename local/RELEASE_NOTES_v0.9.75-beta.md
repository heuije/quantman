# v0.9.75-beta

자동업데이트가 자동매매를 끊지 않도록 고치고, 동시호가에 직접 매매가 섞여도 안전하게
목표 포지션으로 교정합니다.

## 자동매매가 끊기지 않습니다 (중요)
- **업데이트 후에도 이어서 실행** — 새 버전이 자동으로 설치·재시작돼도, 자동매매가
  실행 중이었다면 **버튼을 다시 누르지 않아도** 그대로 이어서 가동됩니다(재시작·예기치
  못한 종료에도 동일). 직전에 직접 '중지'하셨다면 그대로 중지 상태를 유지합니다.

## 수동매매를 해도 동시호가 직후 자동으로 교정
- **동시호가 직전 직접 매매도 반영** — 개장·마감 동시호가 시간에 직접(HTS/MTS) 주문을
  넣으셔도, 자동매매가 그 미체결 주문을 감안해 **중복으로 과하게 사지 않습니다**
  (직접 산 만큼 빼고 나머지만 발주 → 체결 후 목표 수량에 정확히 맞춤).
- **개장·마감 직후 재정렬** — 동시호가 발주 후 취소하셨거나 늦게 주문하신 경우엔
  개장 직후(선물 08:52·주식 09:05) 자동으로 "자동매매로만 운용했을 때의 포지션"으로
  되돌립니다. 마감 임박 건은 다음 개장에 정렬됩니다.

---
*자동 업데이트: 앱 재시작 시(또는 장 마감 후 자동으로) 최신 버전이 적용됩니다.*
