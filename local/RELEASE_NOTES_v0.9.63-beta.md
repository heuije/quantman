# MyStock 로컬앱 v0.9.63-beta

**종가매수(오버나이트 롱) 진입**을 자동매매에 지원하는 업데이트입니다.

## 종가에 사서 다음날 시가에 파는 전략 지원 (핵심)

- 전략빌더 체결 설정을 **"당일 종가"**로 둔 전략(예: *S&P500 신호 → 코스피200선물 종가매수, 익일
  시가매도* 같은 오버나이트 롱)이 이제 자동매매에서 정상 동작합니다.
- 이전 문제: 종가매수 전략도 **아침 시가창(08:55)에서 진입을 시도**하다 다른 시가진입 전략들과
  증거금 경쟁에 밀려 **미체결**되고, 정작 종가에는 진입할 경로가 없었습니다.
- 이제 진입 시점을 체결 설정에 맞춰 나눕니다:
  - **"익일 시가"** 전략 → 아침 시가창에서 진입 (기존과 동일).
  - **"당일 종가"** 전략 → **종가 발주창(주식 15:25·선물 15:40)에서 진입.**
- **익일 시가매도(청산)는 기존 그대로** — 다음날 아침 청산이 처리합니다(코드 변경 없음).

## 안전장치

- 종가 진입에도 **킬스위치·손실한도·자격증명 커버리지** 게이트를 아침 진입과 동일하게 적용합니다.
  특히 장중 손절 감시가 끝난 뒤(15:30) 도는 선물 종가창(15:40)에서도 **일일 손실 한도를 다시 확인**해
  한도 초과 시 신규 진입을 막습니다.
- **종가매수 + 당일청산(보유일수 0)** 처럼 청산 창이 없는 모순 설정은 진입하지 않고 안내합니다
  (오버나이트 롱은 보유일수를 1 이상으로 두세요).
- 종가 진입 계약수는 아침과 같은 방식(브로커 실제 주문가능수량 × 증거금 사용률)으로 계산됩니다.

## 검증

엔진·자동매매 테스트 통과(로컬 690, 종가진입 신규 테스트 9종 포함). **실제 종가창(15:40) 모의계좌
동시 실행 동작은 다음 거래일에 확인**하시길 권합니다 — 특히 청산·진입이 같은 종가창에 겹칠 때의
증거금 반영을 봐주세요.
