# MyStock 로컬앱 v0.9.62-beta

기기 페어링·계좌 연동의 온보딩 흐름을 고친 업데이트입니다.

## 페어링 완료 시 계좌가 웹에 바로 연동 (중요)

- 로컬앱에서 **자격증명 등록 → 페어링**을 마쳤는데도, 웹앱에서 "계좌에 적용"을 누르면
  *"로컬앱에서 계좌를 등록·페어링한 뒤 적용할 수 있습니다"* 만 뜨고 **계좌 선택 창이 안 뜨던**
  문제를 고쳤습니다.
- 원인: 계좌 정보가 서버로 전송되는 시점이 부족했습니다. 자격증명을 먼저 저장하면 그 시점엔
  아직 페어링 토큰이 없어 전송이 실패하고, **페어링 완료 시에는 전송을 하지 않아** 서버에
  계좌가 비어 있었습니다.
- 이제 **페어링이 끝나는 즉시** 계좌 정보를 서버로 보냅니다 → 등록 → 페어링 → 웹에서
  "계좌에 적용" → **내 계좌 선택 창이 정상적으로 뜹니다.**

## 기기 페어링 취소 지원

- 페어링을 시작하면 브라우저 승인을 기다리며 최대 10분간 대기하는데, 그동안 **취소할 수가
  없어** 갇히던 문제를 고쳤습니다.
- 이제 '기기 페어링 시작' 버튼이 대기 중 **'취소'로 바뀌어**, 누르면 즉시 중단하고 처음
  상태로 돌아갑니다. (코드 발급 중에도 취소 가능)

## 검증

엔진·자동매매 테스트 통과(로컬 680 + 신규 페어링 취소 테스트). 페어링→웹 계좌표시 동작은
실제 로컬앱·페어링 환경에서 확인하시면 됩니다.

## 업데이트 방법

로컬앱을 종료하고 이 버전으로 교체한 뒤 다시 실행하세요.
