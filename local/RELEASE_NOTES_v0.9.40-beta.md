# v0.9.40-beta

## 콘솔창 깜빡임 제거 + (v0.9.39) 주문 내역 손익 표시 · 잔고 로딩 안정화

이전 버전에서 바로 업데이트하면 아래 세 가지가 한 번에 적용됩니다.

### 1. 자동매매 중 콘솔창이 깜빡이던 문제 해결 (이번 버전)

앱을 켜두면 자동매매 작업 시각(매매 사이클·체결 등)마다 **검은 터미널 창이
잠깐 떴다 사라지던** 현상을 없앴습니다.

- 원인: 앱이 상태 파일에 보안 권한을 적용할 때 Windows `icacls` 명령을 실행하는데,
  **창을 숨기는 옵션이 빠져** 있어 호출마다 콘솔이 깜빡였습니다. 매매 사이클·체결 때
  잔고·주문 상태를 저장하며 이 명령이 반복돼 그 시각에 집중적으로 나타났습니다.
- 수정: 해당 명령을 **창 없이 실행**하도록 했습니다. 파일 보안(권한 제한) 동작 자체는
  그대로이고, 보이는 창만 사라집니다.

### 2. 주문 내역에 '손익' 표시 (v0.9.39 포함)

주문 내역 탭에 **손익** 칸이 생겼습니다. 청산이 끝난 거래의 실현손익을 바로 봅니다.

- **선물**: 청산이 끝난 거래(당일청산·숏청산 등)에 정산손익이 표시됩니다. 과거
  기록도 즉시 보입니다(예: 코스피200선물 당일청산 +22,187,500).
- **주식**: 이번 업데이트 이후 새로 체결되는 매도부터 실현손익이 표시됩니다(과거
  주식 매도는 '—'). 표시 금액은 수수료·세금 차감 전 금액입니다.

### 3. 잔고 탭 '불러오는 중' 멈춤 해소 (v0.9.39 포함)

잔고가 여러 계좌(주식·선물)를 조회하느라 서버 응답이 느릴 때 **'잔고 불러오는
중…'에서 한참 멈춰** 새로고침도 안 먹던 문제를 고쳤습니다. 20초 안에 응답이 없으면
'조회 지연 — 새로고침' 안내로 바뀌고, 늦게 응답이 와도 정상적으로 채워집니다.

및 파일 보안 계층** 변경 — 발주·체결·손실 제어 등 매매 핵심 로직은 그대로입니다.
실제 화면·콘솔 동작은 이 빌드 설치 후 확인하세요.
