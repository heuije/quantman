# v0.9.27-beta

## 웹↔로컬앱 상태 실시간 동기화

웹앱과 로컬앱의 상태 표시가 어긋나던 문제를 **부류 단위로** 근본 수정했습니다.

### 무엇이 문제였나
로컬앱에서 상태를 바꿔도(예: **Kill Switch 해제**, 일시정지·재개, 주문 취소) 웹앱은
다음 자동 사이클 전까지 **옛 상태 그대로** 표시됐습니다 — 웹은 로컬앱이 스냅샷을 보낼
때만 갱신되는데, 이런 상태 변경들은 스냅샷을 보내지 않았기 때문입니다. (사이클·비상청산은
보냈지만, 해제·일시정지 등은 비대칭적으로 안 보냄.)

### 어떻게 고쳤나
- **모든 상태 변경이 즉시 스냅샷을 전송**합니다 — Kill Switch 해제, 일시정지, 재개,
  주문 취소 시 곧바로 웹에 반영(한 번의 왕복 내). 더 이상 "해제했는데 웹은 활성"이
  남지 않습니다.
- **자동매매 상태(실행 중 / 일시정지 / 정지)를 웹에 표시**합니다. 전엔 웹이 일시정지
  여부를 알 수조차 없었으나, 이제 모든 스냅샷에 자동매매 상태가 실려 웹 트레이딩 화면
  액션 줄에 실시간 표시됩니다.

검증: 신규 단위 테스트(상태 영속·스냅샷 주입·상태 스냅샷) + 로컬 전체 회귀 green.
자동매매 매매 로직은 무변경(주식 byte-identical).
