# v0.9.74-beta

자동매매 주문 방식을 근본부터 다시 설계했습니다 — 수동매매가 섞여도 안전하게 목표 포지션으로 수렴합니다.

## 자동매매 주문 — 목표상태 수렴(핵심)
- **수동매매 자동 흡수** — 직접(HTS/MTS) 거래를 하셔도, 개장·마감 사이클마다 자동매매가
  "자동으로만 운용했을 때의 목표 포지션"으로 계좌를 되돌립니다. 매도했던 계약을 되사고,
  넘치는 계약을 정리하는 걸 **단일 순주문**으로 처리합니다.
- **허위 손익·불필요 매도 제거** — 오래된 시세로 정산되며 생기던 유령 손익, 실제 보유를
  넘어선 잘못된 매도(오버셀)가 **구조적으로 불가능**해졌습니다.
- **"판단 불가"는 청산하지 않음** — 데이터가 오래됐거나 확인 안 되는 종목은 함부로 팔지
  않고 그대로 보유(다음 사이클 재시도) — 오래된 데이터가 전량 청산을 유발하던 위험 차단.

## 선물 개장 타이밍
- **선물 개장 동시호가(08:45) 체결** — 선물 진입 주문을 08:35 개장 동시호가 창에 넣어
  시가 단일가에 체결합니다(기존엔 08:55 연속거래에서 체결돼 불리했습니다).
- **발주 실패 시 안전 재시도** — 주문 접수가 모호한 경우(타임아웃 등) 브로커에 실제 접수
  여부를 확인한 뒤에만 재시도해 **이중 발주를 막습니다**.

## 관측·업데이트
- **목표수렴 상태 표시** — 수동매매를 자동이 되돌린 계약수를 활동 화면에 표시합니다.
- **자동 안전시간 업데이트** — 새 버전이 나오면 장 마감 후(주문·데이터 작업과 겹치지 않는
  안전한 시각) 자동으로 설치·재시작합니다. 원하시면 상단 배너로 즉시 업데이트도 가능합니다.

## 데이터(서버)
- **아침 선물 데이터 신선화** — 서버가 아침에 최신 선물 데이터를 확인·재포장해 전달합니다
  (오래된 선물 데이터로 발주되던 문제의 근본 원인 수정).
