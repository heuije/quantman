# v0.9.76-beta

직접 매매하신 포지션이 **자동매매와 반대 방향**일 때, 자동매매 진입 규모가 의도의
절반으로 줄던 문제를 고쳤습니다.

## 직접 매매가 있어도 제대로 된 규모로 진입합니다

- **무엇이 문제였나** — 직접(HTS/MTS) 매매하신 포지션이 자동매매 전략과 **반대 방향**일 때
  (예: 직접 매도해서 매도 포지션이 있는데 전략은 매수 진입), 자동매매는 그 직접 포지션에
  묶인 증거금을 빼고 계산해 **의도한 절반만** 진입했습니다. 주문 자체는 직접 포지션을
  정상적으로 되돌렸지만, **규모 계산에서만** 되돌리지 않던 불일치였습니다.
- **이제는** — "직접 매매를 전부 정리한 잔고"를 기준으로 진입 규모를 계산합니다. 방향과
  무관하게 동일합니다. 설정하신 사용률(예: 50%)이 그대로 반영됩니다.
- **같은 방향**(직접 매수 + 전략도 매수)은 기존 버전에서 이미 정상이었습니다 — 이번 수정은
  **반대 방향**만 해당합니다.

## 바뀌지 않는 것

- 전략끼리의 청산→진입 인계(같은 방향 넘기기)와, 전략 청산 후 반대 방향 진입 시
  "청산분을 뺀 나머지 여력으로 진입"하는 규칙은 **그대로**입니다.
- 불필요한 매수/매도 없이 **차이만큼만 발주**하는 방식도 그대로입니다.

*자동 업데이트: 앱 재시작 시(또는 장 마감 후 자동으로) 최신 버전이 적용됩니다.*
