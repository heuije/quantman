# MyStock 로컬앱 v0.9.72-beta

**데이터 다운로드 안정성 수정 + 원격 진단 지원**을 담은 업데이트입니다. 기존에 돌고 있는 전략의 동작은 바뀌지 않습니다.

## 무엇이 고쳐졌나

1. **데이터 다운로드(추출)가 중간에 멈추던 문제 근본 수정** — 일부 Windows 환경에서 특정 종목 이름(예: "CON" 같은 Windows 예약 이름) 때문에 데이터 묶음 풀기가 그 파일에서 중단돼, **그 뒤 종목들이 하나도 안 풀려** 자동매매가 조용히 데이터 없이 도는(발주 0) 경우가 있었습니다. 이제 **문제되는 이름은 안전하게 처리**되고, 한 파일이 실패해도 **나머지는 정상적으로 풀립니다.** (서버측 조치는 이미 반영돼 이 버전 없이도 대부분 해소되지만, 이 버전은 로컬에서도 이중으로 방어합니다.)

## 무엇이 새로워졌나

2. **문제 발생 시 원격 진단 지원** — 데이터 다운로드 결과·로드 상태·최근 오류를 상태 동기화에 함께 보내, 문제가 생기면 **매번 「진단 정보 복사」를 요청하지 않고도** 개발자가 원격으로 원인을 파악합니다. **민감정보(계좌·자격증명)는 전송되지 않으며**, 파일 경로의 사용자 이름도 제거됩니다.

## 바뀌지 않은 것 (중요)

- **기존 연동 전략은 전부 그대로입니다.** 발주 로직·수수료·사이징·정상 종목의 데이터 처리 모두 종전과 동일합니다 — 회귀 테스트로 확인했습니다.

## 업데이트 방법

로컬앱을 종료하고 이 버전으로 교체한 뒤 다시 실행하세요.
