# MyStock 로컬앱 v0.9.64-beta

거래 모니터링 화면을 더 친절하게 다듬은 업데이트입니다. (자동매매 로직은 변화 없음 — 표시만 개선)

## 주문 예정 — 발주 시각 + 예상 수량

- 잘 안 와닿던 **점수**를 빼고, **‘주문예정’(발주 시각)**과 **‘예상 수량’**을 넣었습니다.
- 주문예정: 전략의 체결설정으로 계산 — 예) *오늘 15:40 종가* · *다음 영업일 08:55 시가*.
- 예상 수량: **실제 발주와 같은 방식**으로 계산합니다(선물은 브로커 주문가능수량 × 증거금
  사용률). "3계약"·"14주"처럼 단위까지 표시. (발주 시점 자금·현재가에 따라 달라질 수 있습니다.)

## 잔고 — 종합요약 카드

- 잔고 탭 상단에 **평가금액(크게)**과 **오늘 손익(원·%, 수익=빨강/손실=파랑)**을 한눈에 보이는
  요약을 넣었습니다. ‘새로고침’ 또는 탭을 열 때 갱신됩니다.

## 주문 내역 — 한글 상태 + 진입/청산 색

- 상태를 한글로: **접수 / 체결 / 부분체결 / 취소 / 거부**.
- 행 색을 **매수/매도 대신 진입/청산 기준**으로 바꿨습니다(진입=연빨강·청산=연파랑). 숏은
  ‘매도가 진입’이라 매수/매도만으론 헷갈리던 것을 바로잡았습니다. 방향 열도 "진입·매수"·
  "청산·매수(환매)"처럼 함께 표기합니다.

## 화면 여백

- 설명 문구가 왼쪽에 몰려 일찍 줄바꿈되던 것을 고쳐, **창 너비에 맞춰 오른쪽 여백까지** 이어
  쓰도록 했습니다.

엔진·자동매매 테스트 통과(로컬 697, 표시 로직·주문 진입/청산 기록 신규 테스트 포함). 자동매매
발주 로직은 바뀌지 않았습니다. 화면 배치·색은 이 버전으로 교체 후 확인하시면 됩니다.
