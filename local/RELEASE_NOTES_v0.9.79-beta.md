# v0.9.79-beta

가이드 문답(7/19)에서 확정된 정비 — 갈아타기 여력, 동시호가 수동 개입 정합,
업데이트 시간 확대가 핵심입니다.

## 갈아타기(방향 전환)도 청산분을 진입 여력에 반영합니다

- 롱을 청산하고 같은 창에서 숏으로 갈아탈 때, 이제 **청산으로 풀리는 여력을
  숏 진입 크기에 미리 반영**합니다(종전엔 같은 방향 재진입에만 반영).
- LS 계좌는 즉시 적용됩니다(문서·실측으로 안전 확인). KIS 선물은 브로커 응답
  의미의 실측(다음 거래일 모의)이 끝날 때까지 종전 방식 유지 — 확인되면 다음
  버전에서 켜집니다(불확실한 상태로 켜면 의도보다 큰 주문이 나갈 수 있어 보수).
- 주식의 청산 대금 추정도 전일 종가 대신 **동시호가 예상체결가(실시간)** 를
  우선 사용해 더 정확해졌습니다.

## 동시호가에 수동 주문을 내면 즉시 정합합니다 (신규)

- 자동 발주 직후부터 단일가 확정 직전까지 10초 간격으로 감시하는 **동시호가
  가드**가 추가됐습니다(개장·마감 각 2창).
- 자동 주문을 취소·수정하셨으면 목표에 맞춰 다시 냅니다(2회까지 — 계속
  거부하시면 물러나고 다음 수렴에 맡깁니다).
- 수동 주문이 전략 목표를 초과하면 **최신 주문부터 취소**해 목표를 유지합니다.
  모든 개입은 기록으로 남습니다.
- ⚠ 이 기능은 "자동매매 계좌는 엔진 전용"이라는 운영 전제를 따릅니다 — 이
  계좌에서 별도 수동 운용을 하실 계획이면 자동매매를 끄고 하세요.

## 자동 업데이트가 주말·휴장일 낮에도 됩니다

- 안전 시간대에 **한국 비거래일(주말·휴장) 06:10~21:00** 이 추가됐습니다 —
  장이 없는 날 낮에 앱을 켜두기만 하면 업데이트가 끝납니다(기존 16~21시·새벽
  06:10~07:00 유지).

## "지금 한 번 실행" 버튼 제거

- 자동 따라잡기·회차 재시도가 정비되면서 실익이 없어졌고, 장중에 잘못 누르면
  실제 발주가 나가는 위험만 남아 제거했습니다. 놓친 회차는 앱이 스스로
  따라잡습니다.
