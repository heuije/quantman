# MyStock 로컬앱 v0.9.58-beta — 핫픽스

## 🔴 자동매매 사이클 크래시 해결 (긴급)

**증상:** "자동매매 시작"을 눌러도 반응이 없음(발주 0).

**원인:** 자동매매 사이클이 전략을 파싱할 때 `quant_core.ir_engine`을 import하는데, 이 패키지가 엑셀 export 모듈(`openpyxl` 의존)을 무조건 함께 로드하도록 돼 있었습니다. 로컬앱 번들엔 `openpyxl`이 없어 `ModuleNotFoundError`로 **사이클이 크래시하고 60초마다 무한 재시도**(발주 0)했습니다. 자동매매·로컬앱은 엑셀 export를 쓰지 않는데도 그 의존성에 묶인 잘못된 구조였습니다.

**수정:** 엑셀 export를 **지연 로딩(lazy)** 으로 바꿔, `ir_engine`을 import해도 `openpyxl`을 요구하지 않게 했습니다. 자동매매가 정상 동작합니다.

## 검증
- 자동매매 사이클 import 경로 전체가 `openpyxl` 없이 정상 동작 확인.
- core 테스트 554 passed·2 skipped, 백테스트 골든·엑셀 export 회귀 0.
