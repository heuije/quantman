# v0.9.81-beta — 증권사 설정 개선 (KIS 선물 입력·활성 브로커 안전장치)

증권사 자격증명을 등록하고 전환하는 과정을 더 안전하고 명확하게 다듬었습니다.

## 새로 추가

- **KIS 국내선물·해외선물 자격증명 입력 화면** — 그동안 KIS 선물 계좌를 넣을
  자리가 없어 주식 칸에 잘못 넣기 쉬웠습니다. 이제 [계좌 종류]에서 국내선물·
  해외선물을 골라 앱키·시크릿·**선물옵션 계좌번호**(상품코드 03)를 입력하고,
  저장 시점에 실제 조회로 유효성을 확인합니다.

## 고침

- **자격증명 저장과 "활성 브로커 전환"을 분리** — 예전에는 설정 화면에서
  KIS/LS 버튼을 누르는 것만으로 자동매매 실행 증권사가 즉시 바뀌었습니다.
  LS로 매매 중인데 KIS를 등록만 하려다 실행 증권사가 바뀔 수 있어, 이제
  **버튼은 화면 이동만** 하고, 다른 증권사로 매매 중일 때는 저장 시 "활성
  증권사를 전환할까요?"를 **명시적으로 확인**한 뒤에만 바꿉니다(처음 등록하는
  단일 증권사 사용자는 종전처럼 자동 선언 — 불필요한 확인 없음).

- **설치 폴더에 버전 표시 파일** — 앱이 켜질 때마다 설치 폴더에
  `VERSION-<버전>.txt`를 기록합니다. 제자리 업데이트라 폴더명이 옛 버전으로
  남아도, 파일 목록만으로 현재 버전을 알 수 있습니다.

- (내부) 자격증명 조회 경로 정리로 테스트 안정성 개선.

## 주의

- 자동매매 계좌는 **엔진 전용**을 권장합니다. 활성 증권사는 한 번에 하나이며,
  전환은 위 확인 절차를 거칩니다.
