# v0.9.77-beta

앱이 새 버전을 **스스로 확인**합니다 — 창을 열어보지 않아도 자동 업데이트가 걸립니다.

## 자동 업데이트가 진짜 무인이 됩니다

- **무엇이 문제였나** — 새 버전 확인이 "앱을 켤 때 한 번 + 창을 클릭할 때"에만
  일어났습니다. PC를 켜두고 들여다보지 않는 무인 운용에서는 새 버전이 나와도 확인
  자체가 안 돼서, 장 마감 후 자동 설치 기능(16~21시)이 있어도 실제로는 설치되지
  않았습니다.
- **이제는** — 앱이 1시간에 한 번 스스로 새 버전을 확인합니다. 새 버전이 나오면
  아무것도 하지 않아도 안전한 시간대(장 마감 후 · 미체결 주문 없음 · 16~21시)에
  자동으로 설치·재시작됩니다.
- **바뀌지 않는 것** — 설치 시점 판단 기준과 화면 상단의 [지금 업데이트] 수동
  배너는 그대로입니다.

## 참고

이번 버전(v0.9.77)을 받는 것 자체는 기존 방식이라, 마지막으로 한 번만 앱을
재시작하거나 창을 클릭해 주세요. 그 뒤부터는 완전 자동입니다.
