# v0.9.73-beta

자동매매 안정성·진단 정확도 개선 + 데이터 정합.

## 자동매매 안정성·진단
- **KIS 토큰 만료 감지 복구** — 토큰 캐시 구조 변경 이후 만료 경고가 발화되지 않던 문제를 근본
  수정. 이제 토큰 만료 임박을 정확히 감지합니다.
- **실패 표면화 강화** — 정산 중 잔고 조회 실패·KIS 응답 실패가 서버 건강 모니터에 정확히
  드러나도록 개선(이상이 조용히 지나가지 않음).
- **브로커·데이터 준비상태 신호** — 자동매매 실행 전제(브로커 자격증명·데이터 결손 여부)를 서버가
  유저별로 관측해 운영자가 문제를 조기에 진단.

## 데이터 정합
- **해외 유니버스 malformed 심볼 차단** — 유닛·워런트·회사명 등 비티커가 유니버스에 잘못 등록되던
  상류 결함을 수정(불필요 종목·다운로드 감소).

## 내부
- 전략 엔진 방향 조건·진입 fill 표현력 확장 — **기존 전략 동작은 불변**.
