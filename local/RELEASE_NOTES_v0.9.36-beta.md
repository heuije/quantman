# v0.9.36-beta

## 로컬앱 UI 수정 — 자격증명 저장 버튼 가림 해소 + 자동매매 상태 접기

v0.9.35의 UI 개편 직후 발견된 레이아웃 문제 2건을 고쳤습니다.

### 1. 자격증명·페어링 편집 화면에서 저장 버튼이 안 보이던 문제

편집(자격증명·페어링 변경) 화면에서 **자동매매 상태 타임라인**(최대 13행)과 새
**활성 계좌·전략 카드**가 세로 공간을 다 차지해, 창을 최대화해도 KIS 자격증명
**연결 테스트/저장 버튼**이 화면 밖으로 밀려 누를 수 없었습니다.

→ 편집 화면에서는 타임라인과 활성 계좌 카드를 **숨겨** 입력 폼에 전체 공간을 줍니다.
이제 편집 화면에서 모든 입력칸과 저장 버튼이 보입니다.

### 2. 자동매매 상태(스케줄) 접기/펴기

**자동매매 상태** 헤더(◂ "자동매매 상태")를 클릭하면 스케줄 목록을 **접고 펼 수**
있습니다. 접으면 "● 정상 · 로컬앱 N분 전" 한 줄만 남아 세로 공간을 아낍니다.
(헤더 왼쪽 ▾/▸ 표시 = 펼침/접힘)

검증: 헤드리스 렌더 스모크 — 일반 모드(타임라인 표시·접기 토글 동작) / 편집 모드
(타임라인·카드 숨김·입력 폼 전체 표시) 확인.
