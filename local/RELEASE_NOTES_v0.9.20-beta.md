## 표시명을 MyStock으로 + 자동 업데이트 안정화

로컬앱의 표시명을 **마이스톡 → MyStock**으로 통일하고, 인앱 자동 업데이트를
**원자적 폴더 스왑**으로 바꿔 업데이트 중 설치 손상을 원천 차단했다.

### ✨ 변경

- **브랜드 — 표시명 MyStock 통일.** GUI 창·트레이·설치 마법사(installer)·실행
  파일명·다운로드 라벨·서버 API 타이틀까지 "마이스톡"을 전부 **MyStock**으로
  교체. 사용자가 보는 모든 표면에서 이름이 일관된다.
- **자동 업데이트 — 원자적 폴더 스왑.** 업데이트 적용 방식을 기존 "기존 폴더 위에
  덮어쓰기(robocopy 머지)"에서 **설치 폴더를 통째로 교체하는 원자적 스왑**으로
  변경. 교체 실패 시 직전 버전으로 자동 롤백, 잠금 시 안전 중단. 옛 방식이 새/구
  파일을 뒤섞어 드물게 "embedded python interpreter 시작 실패"를 유발하던 문제를
  근본 차단한다.

### 근본 원인 (업데이트)

옛 업데이터는 새 빌드를 기존 설치 폴더 **위에 병합 복사(robocopy /E /XO)** 했다.
빌드 간 내부 구성(파이썬 런타임·base_library)이 달라지면 신·구 파일이 섞여 번들
짝이 깨질 수 있었다. 이제 **빈 폴더에 새 빌드를 통째로 받아 폴더 단위로 원자
교체**하므로, 절반만 적용된 상태가 존재할 수 없다.

> ℹ️ 이 원자적 업데이터는 **이번 빌드부터 설치된 버전에서 효력**이 있다. 즉
> v0.9.19-beta → v0.9.20-beta 이번 업데이트 자체는 아직 이전(머지) 업데이터로
> 적용되지만, 양쪽 모두 Python 3.11 빌드라 짝 손상 위험이 없다. 다음 업데이트
> (v0.9.20 → 이후)부터는 원자 스왑으로 안전하다.

### 4원칙 자가검토

- **근본 ✓** — 업데이트 짝 손상을 가드가 아니라 적용 메커니즘(원자 스왑) 자체로 해결.
- **Over-eng 금지 ✓** — 브랜드는 문자열 치환, 업데이터는 단일 .bat 로직 교체. 새 옵션·플래그 없음.
- **Overthinking 금지 ✓** — 릴리즈 내용 = main에 이미 머지된 변경의 빌드 1회.
- **검증** — web `tsc`·server import·로컬 테스트는 각 머지 PR에서 통과. 이 빌드는
  CI(Python 3.11, Windows+macOS)가 생성. **앱 실제 표시명·업데이트 동작 육안 확인은
  사용자 설치/업데이트 시점**(Tkinter·인스톨러는 자동 캡처 불가).
