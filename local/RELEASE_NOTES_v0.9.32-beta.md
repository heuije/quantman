# v0.9.32-beta

## 주문 가격을 실시간 시세 기준으로 — "상/하한가 오류" 거부 근본 수정 (중요)

2026-06-11(선물 만기일) 코스피200선물 매수가 "모의투자 상/하한가 오류"로 거부된
사고의 근본 수정입니다. 원인은 주문 지정가가 **백테스트용 데이터(전일 종가·선물은
연속물)** 기준으로 계산돼, 실제 거래되는 계약의 가격과 어긋날 수 있던 구조였습니다
(평소엔 차이가 작아 가려지다가 선물 만기·롤 시점에 드러남 — 분기마다 재발 예약).

**바뀐 정책 (업계 표준 정렬): 신호·수량 계산의 근거는 데이터, 주문 가격은 발주
직전 실시간 시세.**

- 즉시 지정가(국내 주식·선물의 진입/청산/숏)는 **발주 직전 KIS 실시간 현재가**
  기준으로 계산합니다 — 선물은 실제 주문 나가는 월물 계약의 시세.
- 가격제한폭(상·하한가)은 자체 ±30% 계산 대신 **거래소가 시세 응답으로 주는
  상·하한가로 클램프** — 주식 ±30%·선물 ±8%·신규상장 ±60% 등이 자동으로 정확.
- 실시간 시세 조회에 실패하면 옛 데이터로 대신 주문하지 않고 **발주를 보류**하고
  사유를 의사결정 로그에 남깁니다(다음 사이클 자동 재시도).
- 미국 예약매수(개장 전)는 시장이 닫혀 있어 전일 종가+버퍼 지정가 유지 — 표준적
  관행 그대로입니다. catch-up의 시초가 지정가도 유지.

## 거부된 주문이 당일 재시도를 막던 문제 수정

주문이 거부(rejected)되면 — 주문 자체가 생성되지 않았는데도 — 내부 멱등 게이트가
"이미 제출됨"으로 남아 **같은 날 같은 종목 재시도가 전부 차단**되던 결함을
수정했습니다. 이제 거부 즉시 게이트가 풀려 다음 사이클/수동 실행에서 정상
재시도됩니다. (06-09 "장종료" 거부 후 그날 내내 재청산 불가였던 메커니즘)

검증: 가격 평면 회귀 테스트 4종(실시간 앵커·시세실패 보류·거래소 밴드 클램프·거부
게이트 해제) + 로컬 전체 345 green. 선물 시세 응답의 상·하한가 필드는 모의 1회
실측으로 최종 확인 예정(없으면 클램프 생략 — KIS 서버가 최종 방어).
