# CSPAT00801 — 현물취소주문

> 소스: `teranum/ls-openapi-samples` `14.주식잔고-미체결-주문.py` 직독 🟢
> 함정은 [GOTCHAS.md](../GOTCHAS.md) 참조.

## Metadata

| 항목 | 값 |
|---|---|
| TR 코드 | `CSPAT00801` |
| 이름 | 현물취소주문 |
| HTTP Method | `POST` |
| PATH | `/stock/order-cancel` ⚠️ 미검증 |
| Base URL | `https://openapi.ls-sec.co.kr:8080` |

## 개요

미체결 주문 취소. 원주문번호(`OrgOrdNo`) + 종목코드 + 취소 수량.

## Request Header

| 필드 | 값 |
|---|---|
| `tr_cd` | `CSPAT00801` |
| `content-type` | `application/json; charset=utf-8` |
| `authorization` | `Bearer {ACCESS_TOKEN}` |
| `tr_cont` | `N` |

## Request Body — InBlock1

블록 키: `CSPAT00801InBlock1`

| 필드명 | 한글명 | Type | 필수 | 값·설명 |
|---|---|---|---|---|
| `OrgOrdNo` | 원주문번호 | long | Y | 🟢 취소할 원래 주문번호 |
| `IsuNo` | 종목번호 | char | Y | 🟢 `"A" + 6자리` |
| `OrdQty` | 주문수량 | long | Y | 🟢 미체결잔량(`ordrem`) 기준 |

> `AcntNo`/`InptPwd` 필요 여부 ⚠️ 미검증.
> `OrdprcPtnCode`/`OrdPrc` 불필요 (취소는 가격 불필요) — 샘플에서 미포함.

## Response Body

```json
{
  "rsp_cd": "00000",
  "rsp_msg": "모의투자 취소주문이 완료 되었습니다.",
  "CSPAT00801OutBlock1": { ... },
  "CSPAT00801OutBlock2": { ... }
}
```

### OutBlock2 핵심 필드 ⚠️ 모두 미검증

| 필드명 | 설명 |
|---|---|
| `OrdNo` | 취소 주문번호 |
| `OrdTime` | 취소 시각 |

## 모의/실전 차이

| 항목 | 내용 |
|---|---|
| 도메인 | 단일 도메인 (G2 참조) — 모의/실전 동일 URL, 키로 분기 |
| 키 | 모의용 appkey/appsecretkey 별도 발급 |
| 종목코드 | ⚠️ 모의는 `"A" + 종목코드`, 실전은 확인 필요 (G9) |

> 현물주문 계열(신규 `CSPAT00601`/정정 `CSPAT00701`/취소 `CSPAT00801`)은 모의/실전 차이가 동일하다.

## 한계

- 이미 전량 체결된 주문은 취소 불가.
- `ordrem = 0`인 주문은 취소 시도 자체가 오류 반환 예상.
