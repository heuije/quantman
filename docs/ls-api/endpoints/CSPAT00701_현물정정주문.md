# CSPAT00701 — 현물정정주문

> 소스: `teranum/ls-openapi-samples` `14.주식잔고-미체결-주문.py` 직독 🟢
> 함정은 [GOTCHAS.md](../GOTCHAS.md) 참조.

## Metadata

| 항목 | 값 |
|---|---|
| TR 코드 | `CSPAT00701` |
| 이름 | 현물정정주문 |
| HTTP Method | `POST` |
| PATH | `/stock/order-modify` ⚠️ 미검증 |
| Base URL | `https://openapi.ls-sec.co.kr:8080` |

## 개요

미체결 주문의 가격(또는 수량) 정정. 원주문번호(`OrgOrdNo`) + 종목코드 + 정정 수량/가격.

## Request Header

| 필드 | 값 |
|---|---|
| `tr_cd` | `CSPAT00701` |
| `content-type` | `application/json; charset=utf-8` |
| `authorization` | `Bearer {ACCESS_TOKEN}` |
| `tr_cont` | `N` |

## Request Body — InBlock1

블록 키: `CSPAT00701InBlock1`

| 필드명 | 한글명 | Type | 필수 | 값·설명 |
|---|---|---|---|---|
| `OrgOrdNo` | 원주문번호 | long | Y | 🟢 정정할 원래 주문번호 (t0425 OutBlock1.`ordno`) |
| `IsuNo` | 종목번호 | char | Y | 🟢 `"A" + 6자리` (G9 참조) |
| `OrdQty` | 주문수량 | long | Y | 🟢 미체결잔량 (`ordrem`) 기준으로 설정 |
| `OrdprcPtnCode` | 호가유형코드 | char(2) | Y | 🟢 `"00"` 지정가, `"03"` 시장가 |
| `OrdCndiTpCode` | 주문조건구분 | char(1) | Y | `"0"` = 없음, `"1"` = IOC, `"2"` = FOK ⚠️ 미검증 |
| `OrdPrc` | 주문가 | double | Y | 🟢 정정 가격 (지정가 시). 시장가는 `0` |

> `AcntNo`/`InptPwd` 포함 여부: 샘플 코드에서 InBlock1에 없으나, 서버 필수 여부 ⚠️ 미확인.

### OutBlock2 핵심 필드 ⚠️ 모두 미검증

| 필드명 | 설명 |
|---|---|
| `OrdNo` | 정정 후 새 주문번호 (원주문번호와 다를 수 있음) |
| `OrdTime` | 정정 시각 |

## 모의/실전 차이

| 항목 | 내용 |
|---|---|
| 도메인 | 단일 도메인 (G2 참조) — 모의/실전 동일 URL, 키로 분기 |
| 키 | 모의용 appkey/appsecretkey 별도 발급 |
| 종목코드 | ⚠️ 모의는 `"A" + 종목코드`, 실전은 확인 필요 (G9) |

> 현물주문 계열(신규 `CSPAT00601`/정정 `CSPAT00701`/취소 `CSPAT00801`)은 모의/실전 차이가 동일하다.

## 한계

- 취소는 `CSPAT00801` 사용.
- 이미 체결된 수량은 정정 불가.
- 미체결잔량(`ordrem`) 기준으로 OrdQty 설정해야 함.
