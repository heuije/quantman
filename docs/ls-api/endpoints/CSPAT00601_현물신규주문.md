# CSPAT00601 — 현물신규주문

> 소스: `teranum/ls-openapi-samples` `14.주식잔고-미체결-주문.py` 직독 🟢

## 개요

국내주식 현물 신규주문. 매수·매도 통합 TR — `BnsTpCode`로 구분.

> 🟢 KIS(`TTTC0011U`/`TTTC0012U` 분리)와 달리 LS는 단일 TR.
> ⚠️ xingAPI legacy는 `CSPAT00600`였으며, REST OpenAPI에서는 `CSPAT00601`로 버전 올라감 (커뮤니티 wrapper 샘플에서 확인).

## Request Body — InBlock1

블록 키: `CSPAT00601InBlock1`

| 필드명 | 한글명 | Type | Length | 필수 | 값·설명 |
|---|---|---|---|---|---|
| `AcntNo` | 계좌번호 | char | 20 | Y | 계좌번호 전체 (⚠️ 형식 G6 참조) |
| `InptPwd` | 입력비밀번호 | char | 8 | Y | 계좌 비밀번호 ⚠️ 미검증 — 요구 여부 확인 필요 |
| `IsuNo` | 종목번호 | char | 12 | Y | 🟢 `"A" + 6자리 종목코드` (예: `"A005930"`). G9 GOTCHA 참조 |
| `OrdQty` | 주문수량 | long | 16 | Y | 주문 수량 (정수) |
| `OrdPrc` | 주문가 | double | 13.2 | Y | 주문 가격. 시장가는 `0` |
| `BnsTpCode` | 매매구분 | char | 1 | Y | 🟢 `"1"` = 매도, `"2"` = 매수 (G7 참조) |
| `OrdprcPtnCode` | 호가유형코드 | char | 2 | Y | 🟢 `"00"` = 지정가, `"03"` = 시장가 (G8 참조) |
| `MgntrnCode` | 신용거래코드 | char | 3 | Y | 일반: `"000"` |
| `LoanDt` | 대출일 | char | 8 | N | 신용 대출일 `YYYYMMDD`. 일반은 `""` |
| `OrdCndiTpCode` | 주문조건구분 | char | 1 | Y | `"0"` = 없음. ⚠️ IOC/FOK 값 미확인 |

> 소스: CSPAT00600.res InBlock1 (ermaker/xingAPI) + 샘플 코드 교차 확인. `AcntNo`/`InptPwd` 필드는 REST wrapper 샘플에서 생략된 경우 있음 — ⚠️ 필수 여부 키 발급 후 확인.

## Response Body — OutBlock1 (입력 에코) / OutBlock2 (주문 결과)

### OutBlock2 — 주문 결과 (핵심)

블록 키: `CSPAT00601OutBlock2`

| 필드명 | 한글명 | Type | 설명 |
|---|---|---|---|
| `OrdNo` | 주문번호 | long | 🟢 주문 번호 — 정정·취소에 사용 |
| `OrdTime` | 주문시각 | char(9) | ⚠️ 미검증 형식. xingAPI 기준 `HHMMSSMMM` |
| `OrdMktCode` | 주문시장코드 | char(2) | ⚠️ 미검증 |
| `OrdPtnCode` | 주문유형코드 | char(2) | ⚠️ 미검증 |
| `ShtnIsuNo` | 단축종목번호 | char(9) | ⚠️ 미검증 |
| `OrdAmt` | 주문금액 | long | ⚠️ 미검증 |
| `AcntNm` | 계좌명 | char(40) | ⚠️ 미검증 |
| `IsuNm` | 종목명 | char(40) | ⚠️ 미검증 |

> 🟢 OrdNo 사용 확인: 샘플 코드에서 `response.body['rsp_msg']` 체크 패턴 확인.
> OutBlock2 전체 필드는 CSPAT00600.res 기준 — REST CSPAT00601과 일부 다를 수 있음.

## 모의/실전 차이

| 항목 | 내용 |

## 한계·주의

- `rsp_msg`로 성공/실패 메시지 확인 가능 (🟢 샘플에서 확인).
- 취소는 별도 TR `CSPAT00801` (정정은 `CSPAT00701`).
- 시장가 주문: `OrdPrc=0`, `OrdprcPtnCode="03"`.
