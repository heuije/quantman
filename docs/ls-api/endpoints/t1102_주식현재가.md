# t1102 — 주식현재가

> 소스: `teranum/ls-openapi-samples` `04.주식현재가.py` 직독 🟢
> LS 공식 howto-sample 페이지 (t1101 유사 TR 구조 확인) 🟢
> 함정은 [GOTCHAS.md](../GOTCHAS.md) 참조.

## Metadata

| 항목 | 값 |
|---|---|
| TR 코드 | `t1102` |
| 이름 | 주식현재가 |
| HTTP Method | `POST` |
| PATH | `/stock/market-data` ⚠️ 미검증 (t1101과 같은 경로일 수 있음) |
| Base URL | `https://openapi.ls-sec.co.kr:8080` |

## 개요

국내 주식 현재가·OHLC·거래량 등 종목 기본 시세 조회.
`shcode` 한 필드만 요청해서 160개 이상의 시세 필드를 받는 단순한 TR.

> `t1101` = 현재가+호가 통합 TR. `t1102` = 현재가 특화.
> 자동매매에서는 현재가 확인용으로 t1102 사용.

## Request Header

| 필드 | 값 |
|---|---|
| `tr_cd` | `t1102` |
| `content-type` | `application/json; charset=utf-8` |
| `authorization` | `Bearer {ACCESS_TOKEN}` |
| `tr_cont` | `N` |

## Request Body — t1102InBlock

블록 키: `t1102InBlock`

| 필드명 | 한글명 | 필수 | 값·설명 |
|---|---|---|---|
| `shcode` | 단축코드 | Y | 🟢 6자리 종목코드 (예: `"005930"`). `"A"` 접두사 불필요 |

## Response Body — t1102OutBlock

블록 키: `t1102OutBlock` (단일 객체, 배열 아님)

총 160+ 필드. 핵심 필드만:

| 필드명 | 한글명 | 설명 |
|---|---|---|
| `hname` | 종목명 | 🟢 |
| `price` | 현재가 | 🟢 현재 거래가 |
| `sign` | 전일대비부호 | 🟢 `"2"` = 상승, `"5"` = 하락 ⚠️ 전체 코드값 미검증 |
| `change` | 전일대비 | 🟢 가격 변동분 (포인트) |
| `diff` | 등락률 | 🟢 % 단위 |
| `volume` | 누적거래량 | 🟢 당일 누적 거래량 |
| `open` | 시가 | 🟢 |
| `high` | 고가 | 🟢 |
| `low` | 저가 | 🟢 |
| `recprice` | 기준가 | 🟢 전일 종가(기준가) |
| `avg` | 가중평균가격 | 🟢 당일 VWAP |
| `uplmtprice` | 상한가 | 🟢 당일 상한가 |
| `dnlmtprice` | 하한가 | 🟢 당일 하한가 |

> 위 필드들은 샘플 코드 실행 결과(출력 예시)에서 직접 확인됨.
> 전체 160 필드 목록은 키 발급 후 DevCenter 또는 실 호출로 확인.
