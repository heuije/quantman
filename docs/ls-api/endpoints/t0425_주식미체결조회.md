# t0425 — 주식미체결조회

> 소스: `teranum/ls-openapi-samples` `14.주식잔고-미체결-주문.py` 직독 🟢
> 함정은 [GOTCHAS.md](../GOTCHAS.md) 참조.

## Metadata

| 항목 | 값 |
|---|---|
| TR 코드 | `t0425` |
| 이름 | 주식미체결조회 |
| HTTP Method | `POST` |
| PATH | `/stock/accno` ⚠️ 미검증 — t0424와 동일 경로일 수 있음 (tr_cd로 구분) |
| Base URL | `https://openapi.ls-sec.co.kr:8080` |

## 개요

당일 미체결(또는 체결/전체) 주문 목록. 정정·취소 전 `ordno`·`ordrem` 조회용.

## Request Header

| 필드 | 값 |
|---|---|
| `tr_cd` | `t0425` |
| `content-type` | `application/json; charset=utf-8` |
| `authorization` | `Bearer {ACCESS_TOKEN}` |
| `tr_cont` | `N` (초회) |
| `tr_cont_key` | `""` |

## Request Body — t0425InBlock

블록 키: `t0425InBlock`

| 필드명 | 한글명 | 필수 | 값·설명 |
|---|---|---|---|
| `expcode` | 종목코드 | N | 🟢 특정 종목만 조회. 빈 문자열 = 전 종목 |
| `chegb` | 체결구분 | N | 🟢 `"0"` = 전체, `"1"` = 체결, `"2"` = 미체결 |
| `medosu` | 매도수구분 | N | 🟢 `"0"` = 전체, `"1"` = 매도, `"2"` = 매수 |
| `sortgb` | 정렬기준 | N | 🟢 `"1"` = 주문번호 역순(최신), `"2"` = 순 |
| `cts_ordno` | 연속조회키 | N | 🟢 연속 조회 시 이전 `cts_ordno` 값 |

## Response Body

블록 구조: `t0425OutBlock` (요약) + `t0425OutBlock1[]` (주문별 배열)

### t0425OutBlock1[] — 주문별 내역 (배열)

| 필드명 | 한글명 | 설명 |
|---|---|---|
| `ordno` | 주문번호 | 🟢 주문 번호 — 정정·취소의 `OrgOrdNo` |
| `expcode` | 종목코드 | 🟢 6자리 종목코드 |
| `medosu` | 매도수구분 | 🟢 "매도" / "매수" 문자열 반환 |
| `qty` | 주문수량 | 🟢 원주문 수량 |
| `price` | 주문가격 | 🟢 원주문 가격 |
| `ordrem` | 미체결잔량 | 🟢 아직 미체결된 수량 — 정정·취소의 `OrdQty` |
| `price1` | 현재가 | 🟢 해당 종목 현재가 |
| `orgordno` | 원주문번호 | 🟢 정정 시 원래 주문번호. 신규는 `0` |
| `ordtime` | 주문시간 | 🟢 주문 시각 (`HHMMSSMMM` 추정) ⚠️ 형식 미검증 |

> 위 필드명은 샘플 코드에서 직접 추출한 것으로 🟢 신뢰도 높음.
> 추가 필드(`hname`, `cntrgb`, `ftradegb` 등)는 ⚠️ 미확인.

## 응답 예시

```json
{
  "rsp_cd": "00000",
  "t0425OutBlock1": [
    {
      "ordno": 16086,
      "expcode": "005930",
      "medosu": "매수",
      "qty": 1,
      "price": 80000,
      "ordrem": 1,
      "price1": 81300,
      "orgordno": 0,
      "ordtime": "112251750"
    }
  ]
}
```

## 한계

- `chegb="2"` (미체결)로 조회하면 이미 체결된 건은 나오지 않음.
- OutBlock1 없을 때 (미체결 0건) `response.body.get('t0425OutBlock1')` None 체크 필수.
- 연속 조회: `cts_ordno` 빈 값이면 마지막 페이지.
