# t0424 — 주식잔고조회2

> 소스: `teranum/ls-openapi-samples` `14.주식잔고-미체결-주문.py` 직독 🟢
> LS 공식 howto-sample 페이지 🟢
> 함정은 [GOTCHAS.md](../GOTCHAS.md) 참조.

## Metadata

| 항목 | 값 |
|---|---|
| TR 코드 | `t0424` |
| 이름 | 주식잔고조회2 |
| HTTP Method | `POST` |
| PATH | `/stock/accno` 🟢 |
| Base URL | `https://openapi.ls-sec.co.kr:8080` |

## 개요

보유 포지션(체결기준 잔고) 목록 조회. OutBlock1이 종목별 배열.

> `chegb="2"` (체결기준잔고)가 실용적 — 결제 전이지만 체결된 종목 포함.
> `chegb="0"` (결제기준잔고) = 이미 결제 완료된 것만.

## Request Header

| 필드 | 값 |
|---|---|
| `tr_cd` | `t0424` |
| `content-type` | `application/json; charset=utf-8` |
| `authorization` | `Bearer {ACCESS_TOKEN}` |
| `tr_cont` | `N` (초회), `Y` (연속) |
| `tr_cont_key` | `""` (초회), 이전 응답 키 (연속) |

## Request Body — t0424InBlock

블록 키: `t0424InBlock`

| 필드명 | 한글명 | 필수 | 값·설명 |
|---|---|---|---|
| `prcgb` | 단가구분 | N | 🟢 `"1"` = 평균단가, `"2"` = BEP단가 |
| `chegb` | 체결구분 | N | 🟢 `"0"` = 결제기준, `"2"` = 체결기준 (권장: `"2"`) |
| `dangb` | 단일가구분 | N | 🟢 `"0"` = 정규장, `"1"` = 시간외단일가 |
| `charge` | 제비용포함여부 | N | 🟢 `"0"` = 미포함, `"1"` = 포함 |
| `cts_expcode` | CTS종목번호 | N | 🟢 연속 조회 시 이전 OutBlock의 `cts_expcode` 값 설정 |

## Response Body

블록 구조: `t0424OutBlock` (요약) + `t0424OutBlock1` (종목별 배열)

### t0424OutBlock — 잔고 요약

| 필드명 | 한글명 | 설명 |
|---|---|---|
| `cts_expcode` | CTS종목번호 | 🟢 연속 조회 키. 비어있으면 마지막 페이지 (G5 참조) |
| `mamt` | 시가총액 | ⚠️ 미검증 정확 의미 |
| `sunamt` | 평가금액 | ⚠️ 미검증 |
| `dtsunik` | 당일실현손익 | 🟢 당일 손익 |
| `tdtsunik` | 총당일실현손익 | 🟢 누적 당일 손익 |

### t0424OutBlock1[] — 종목별 잔고 (배열)

| 필드명 | 한글명 | 설명 |
|---|---|---|
| `expcode` | 종목코드 | 🟢 6자리 종목코드 |
| `hname` | 종목명 | 🟢 종목명 |
| `janqty` | 잔고수량 | 🟢 보유 수량 |
| `mdposqt` | 매도가능수량 | 🟢 매도 가능 수량 |
| `pamt` | 평균단가 | 🟢 평균 매입단가 |
| `price` | 현재가 | 🟢 현재가 |
| `mamt` | 시가평가금액 | ⚠️ 미검증 |
| `appamt` | 매입금액 | 🟢 매입 총금액 |
| `dtsunik` | 당일실현손익 | 🟢 당일 손익 |
| `sunikrt` | 수익률 | 🟢 수익률 (%) |
| `fee` | 수수료 | ⚠️ 미검증 |
| `tax` | 세금 | ⚠️ 미검증 |
| `jonggb` | 종류구분 | ⚠️ 미검증 (2, 3, 9 등) |
