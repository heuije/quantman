# 코스피200 REVERSION — 혼합전략 기준 · 이중 렌즈 설계

작성 2026-07-01. 대상: 선물분석 대시보드의 **코스피200 REVERSION** 섹션.

## 배경 / 요구

기존 REVERSION은 원지수(코스피200선물 종가)에 대해 급등락→회귀를 분석했다. 사용자는 기준 시리즈를
**특정 혼합전략의 수익률**로 바꾸고, 두 관점(렌즈)을 각각 지원하기를 원했다.

**혼합전략(둘 동시 운용):**
- **전략1 (S&P 신호 당일매매):** 직전 미국 S&P500 세션이 하락 마감 → 코스피200선물 시가매수·종가매도(당일 롱);
  상승 마감 → 시가매도·종가청산(당일 숏). 부호 `s = -sign(S&P 전일대비)`.
  `r1 = s·(close/open − 1)`
- **전략2 (오버나이트 롱):** 매일 종가매수·익일 시가매도. `r2 = open_t/close_{t−1} − 1`
- 일별 지수수익 합산: `idx_ret = r1 + r2` (두 다리는 오버나이트→당일로 시간상 인접하나 각자 1단위 명목).

선물이라 **레버리지 N배**: 일일 실현 계좌수익 `d = max(−1, N·idx_ret)` — floor(−1) = 하루 −100% = **강제청산**
(원금 이상 못 잃음). 청산 시 다음날 **새 자본 1.0으로 재시작**(세그먼트 분할) — 전 구간 생존.

## 두 렌즈 (같은 원천 `d` 에서 파생)

### 렌즈 A — 자본곡선 (레벨 회귀, 기존 방식 재사용)
- `d` 복리 누적 = 자본곡선(청산 시 리셋). 기준 시리즈로 사용.
- 기존 `reversion_events`(전환임계 ZigZag 피벗 → 급등락임계 누적 → N일 회귀)를 **세그먼트별**로 돌려 병합.
- **레버리지 이중적용 방지:** 곡선이 이미 N배 계좌기준 → 엔진은 `leverage=1`로 그 곡선에 직접 임계 적용.
  전환·급등락 임계·회귀수익률·청산은 전부 계좌 % (곡선 자체 %).

### 렌즈 B — 일일 실현수익률 (스트릭 → 이후 수익, 신규)
- `d` 시계열에서 관측창 `W`일 평균 `A_t`. `A_t ≥ +θ%` = 과열(HOT), `A_t ≤ −θ%` = 과냉(COLD).
- 이후 `H`일 **누적수익** `∏(1+d[t+1..t+H]) − 1` (청산 반영 → 청산 시 −1.0).
- **비겹침:** 신호 발생 시 이후 H일을 건너뜀(forward 윈도우 독립).
- 방향별 요약: n · 평균 · 중앙값 · 상승비율 · 청산율.

## 결정 (사용자 합의)

| 항목 | 결정 | 근거 |
|---|---|---|
| 자본곡선 레버리지 | 회귀 입력 N배로 곡선을 그림 (계좌기준) | "레버리지 반영 곡선을 직접 표시" |
| 청산 처리 | 하루 −100% floor → 다음날 새 자본(세그먼트) | "일일수익 곡선 · 청산 시 새 자본 재시작" |
| 렌즈 B 이후 지표 | 이후 H일 **누적**수익률(총, 청산반영) | 실행 관점(들고 가면 얼마) |
| 렌즈 B 표본 | **비겹침** 창(신호 후 H 스킵) | forward 독립성(통계 신뢰) |
| 범위 | 코스피200 전용 | S&P→코스피 특정 전략. 타 종목 무영향 |

## 실측 검증 (2010–2026, KOSPI static + S&P500 캐시)

- **5배:** 곡선 전구간 생존(최종 ×13.9)·세그먼트 1. 렌즈A 하락소진→롱 회귀평균 +27.5%(성공 74%). 렌즈B 과냉 이후 +8.3%.
- **10배:** 세그먼트 2·청산 1건(2024-08-05 엔캐리). 변동성 drag로 곡선 감쇠. 렌즈B 과열 이후 −0.5%(되돌림)·과냉 +24.4%.
- 5배 최종배수(×13.85)는 독립 프로브와 일치(교차검증).

## 한계 / 미해결

- **엑셀 내보내기(코스피):** 자본곡선이 경로의존(청산 리셋)이라 레버리지-라이브 재계산 수식이 어려움 →
  코스피는 엑셀 버튼 숨김(원지수 종목은 기존대로). 정적 데이터 export 방식은 후속 결정.
- 렌즈 A 청산율: 곡선이 이미 레버리지 반영이라 세그먼트 내 counter-trend 청산은 거의 0(위험은 곡선 크기에 내재).
- 종가 기반·비용/체결 미반영(관계 측정용) — 기존 REVERSION과 동일.
